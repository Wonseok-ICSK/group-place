# 룰렛 설계 (v0.4.0)

작성 2026-10-26. "다음엔 어디 갈까"를 정해 주는 기능. 장소 월드컵이 다녀온 곳 중 최고를 고른다면, 룰렛은 가고 싶은 곳 중 하나를 무작위로 뽑는다.

## 0. 결정 사항 (운영자 2026-10-26)

| # | 결정 |
|---|---|
| 1 | 친구용 앱(group-place)에만 넣는다. 공개해도 되는 기능이라 `main`에 둔다 |
| 2 | 후보는 기본으로 **가고 싶은 곳**만. "다녀온 곳도 넣기"를 켜면 다녀온 곳도 후보가 된다 |
| 3 | 카테고리를 골라서 돌린다(전체 포함). 처음에는 목록에서 고른 카테고리가 그대로 |
| 4 | 결과는 **남기지 않는다**(DB 변경 없음, SQL 없음). 대신 **공유하기**: 휴대폰 공유 창(카카오톡 등)으로 결과를 보냄 |
| 5 | 공개 방 둘러보기(읽기 전용)에서는 쓰지 않는다 |

## 1. 화면

- **여는 곳**: 머리의 장소 월드컵(트로피) 단추 옆에 룰렛 단추(`data-action="roulette"`, 아이콘 + `aria-label="룰렛"`). 읽기 전용(`ro()`)에서는 그리지 않고, 눌러도 아무 일도 하지 않는다.
  `VISIT_ACTIONS`(읽기 전용 허용 목록)에는 넣지 않는다.
- **시트 `roulette`** (다른 시트와 같은 `openSheet`/`drawSheet` 흐름). 단계 셋:
  1. **고르기**: 카테고리 칩(전체 + 방의 카테고리, 처음 값 = 목록의 지금 카테고리 필터), "다녀온 곳도 넣기" 켜기/끄기(처음 끔),
     후보 목록(체크로 이번만 빼기, 처음엔 모두 포함), "후보 N곳", [돌리기]. 후보가 2곳 미만이면 [돌리기]를 끄고 이유를 보여 준다
     ("가고 싶은 곳이 2곳 이상이어야 돌릴 수 있어요" 등).
  2. **돌아가는 중**: 후보가 12곳 이하면 원판(SVG 부채꼴, 이름은 짧게 줄여서), 13곳 이상이면 이름이 빠르게 넘어가다 멈추는 칸.
     약 3~4초. 이 동안 단추는 잠그고, 시트를 닫으면 타이머를 모두 멈춘다. `prefers-reduced-motion: reduce`면 움직임 없이 바로 결과.
  3. **결과**: "○○로 정해졌어요!" 카드(이름, 카테고리, 주소, 상태). 단추: [지도에서 보기], [이 장소 열기](상세 시트, 그사이 지워졌으면 숨김),
     [다시 돌리기](같은 후보로), [공유하기], [후보 다시 고르기]. 결과는 `aria-live`로 읽어 준다.
- 방을 바꾸거나 다시 불러와 장소가 바뀌면 다른 시트와 같은 규칙으로 닫거나 후보를 다시 만든다(지워진 장소가 결과로 나오지 않게).

## 2. 뽑기와 계산 (DOM 없는 함수로 따로 두고 시험)

- `rouletteCandidates(places, { cat, withVisited })` → 후보 배열. `cat`이 `''`/`null`이면 전체. 가고 싶은 곳(`status === 'want_to_go'`) + (켜면) 다녀온 곳.
  담은 순서(최신 먼저)로.
- `fairIndex(n, rand)` → `0..n-1` 정수. `rand()`는 32비트 부호 없는 정수를 주는 함수(기본 `crypto.getRandomValues`).
  나머지 연산 치우침이 없게 **거절 표본**(2^32를 n으로 나눈 몫의 배수 밖이면 다시 뽑기)으로.
- `wheelTarget(index, n, turns, current)` → 원판의 다음 회전 각도(도). 뽑힌 칸의 가운데가 위쪽 바늘에 오게, 지금 각도보다 `turns`바퀴 이상 더 돈 값.
- `rouletteShareText(place)` → 공유 글:
  ```
  🎯 룰렛으로 정했어요: <이름>
  <카테고리> · <주소(있으면)>
  <지도 링크>
  ```
  지도 링크는 장소의 지도 링크가 아는 지도 주소(공개 방 `publicMapUrl`과 같은 규칙)면 그것, 아니면 네이버 지도 검색 주소(이름 + 주소).
  사이트 주소는 넣지 않는다.

## 3. 공유하기

1. `navigator.canShare({ files })`가 되면: 결과 카드를 캔버스로 그린 PNG(예: 1080×1080, 앱 색, 이름·카테고리·주소·날짜)와 공유 글을 함께 `navigator.share`.
2. 파일 공유가 안 되면 글만 `navigator.share({ title: '룰렛 결과', text })`.
3. `navigator.share`가 없으면(PC 등) 글을 클립보드에 복사하고 "복사했어요" 안내. 복사도 안 되면 글을 골라 둘 수 있게 보여 준다.
- 사용자가 공유 창을 닫은 것(`AbortError`)은 오류로 보지 않는다. 캔버스에는 글자를 그릴 뿐이라 이름에 특수 문자가 있어도 안전.
